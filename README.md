# Album du musée

Petite appli web (PWA) pour visiter un musée en famille : on remplit des cadres (« la plus rigolote », « celle qui fait le plus peur »…) avec des photos, on gagne des étoiles, puis on vote pour garder une photo par cadre.

- Aucune donnée ne quitte le téléphone : album et photos sont stockés dans le navigateur.
- Option : chaque photo est aussi enregistrée dans la galerie (iPhone : feuille de partage, Android : dossier Téléchargements).
- Fonctionne sans réseau une fois ajoutée à l'écran d'accueil.
